Datenschutz

Diese Website verwendet in der aktuellen Version keine Analyse- oder Marketing-Cookies und bindet keine externen Tracking-Skripte ein. Eingaben in die Rechner werden ausschließlich im Browser verarbeitet und nicht an RechnerWerk übertragen.

Hosting

Die Website wird über GitHub Pages bereitgestellt. Beim Aufruf können technisch notwendige Server-Logdaten durch den Hosting-Anbieter verarbeitet werden.
