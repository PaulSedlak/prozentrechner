# SolarPlan – PV-Wirtschaftlichkeitsrechner

Statische Website für GitHub Pages, ohne Build-Tools oder externe JavaScript-Bibliotheken.

## Upload
Alle Dateien in das Root-Verzeichnis deines GitHub-Pages-Repositories hochladen.

## Enthalten
- Live-Eingaben und Slider
- PV vs. PV + Speicher
- Amortisation und IRR
- Cashflow-Diagramm
- Energieverteilung
- Strompreis-Sensitivität
- Responsive Design

Vor produktiver Veröffentlichung Impressum und Datenschutz anpassen.
